# 🎯 الإتقان موبايل - موقع الوظائف المتاحة

## Aletqan Mobile - Careers Website

---

## 📋 نبذة عن المشروع

موقع احترافي وإبداعي لعرض الوظائف المتاحة في شركة الإتقان موبايل (Aletqan Mobile).
الموقع مصمم بطريقة عصرية وسهلة الاستخدام ليساعد الباحثين عن عمل على معرفة الفرص الوظيفية المتاحة.

---

## 🌟 الميزات الرئيسية

✅ **تصميم احترافي وحديث** - واجهة مستخدم جميلة وسهلة التنقل

✅ **دعم اللغة العربية** - محتوى كامل باللغة العربية بتنسيق RTL

✅ **وظائف متعددة** - عرض تفاصيل دقيقة لكل وظيفة:
- خدمة العملاء 📞
- صيانة الأجهزة 🔧
- موظفو المبيعات 📊

✅ **معلومات شاملة** - تفاصيل التقديم والتواصل والموقع

✅ **تصميم مستجيب** - يعمل بشكل مثالي على جميع الأجهزة (Desktop, Tablet, Mobile)

✅ **رسوم توضيحية وأيقونات** - تصميم مرئي جذاب وسهل الفهم

✅ **حركات وتأثيرات سلسة** - تجربة مستخدم احترافية مع animations

## 🚀 البدء السريع

### 1. استنساخ المستودع
```bash
git clone https://github.com/zahiabulhoul-svg/aletqan-careers.git
cd aletqan-careers
```

### 2. فتح الموقع
ما عليك سوى فتح ملف `index.html` في متصفحك:
```bash
open index.html
# أو
start index.html  # على Windows
```

### 3. أو استخدام خادم محلي
```bash
python -m http.server 8000
# ثم اذهب إلى http://localhost:8000
```
